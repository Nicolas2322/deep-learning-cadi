# Semana 1 - Neurona Vainilla

## Objetivo

Comprender el funcionamiento básico de una neurona artificial mediante la implementación manual de sus componentes principales: pesos, bias y función de activación.

## Metodología

Se implementó una neurona simple utilizando operaciones matemáticas básicas. Se definieron manualmente los pesos y el bias, y se utilizó una función de activación tipo escalón (step) para determinar la salida.

## Componentes evaluados

* Pesos (w1, w2)
* Bias (b)
* Función de activación (step)
* Cálculo de la variable z

## Resultados

La neurona logró replicar el comportamiento de la compuerta lógica AND, generando una salida de 1 únicamente cuando ambas entradas son 1, y 0 en los demás casos.

## Conclusión

Este ejercicio permitió entender cómo una neurona toma decisiones a partir de una combinación lineal de entradas. Además, se evidenció cómo el bias influye en el umbral de activación.

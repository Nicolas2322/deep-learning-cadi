# Semana 14 – Actividad 14: Aplicación de GANs

## Objetivo

Implementar una Red Generativa Adversaria (GAN) utilizando TensorFlow/Keras para comprender el funcionamiento del generador y discriminador en la creación de imágenes sintéticas.

## Dataset utilizado

Fashion MNIST.

## Arquitectura implementada

- Generador basado en capas Dense y Conv2DTranspose.
- Discriminador basado en capas convolucionales Conv2D.

## Evidencia principal

El modelo logra generar imágenes sintéticas similares a prendas de vestir mediante entrenamiento adversarial entre el generador y el discriminador.

## Tecnologías utilizadas

- Python
- TensorFlow/Keras
- NumPy
- Matplotlib

## Cómo ejecutar

1. Abrir el notebook en Google Colab.
2. Ejecutar todas las celdas en orden.
3. Esperar el entrenamiento y visualizar imágenes generadas.

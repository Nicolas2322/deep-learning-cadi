# Semana 14 – Actividad 14: Aplicación de GANs

## Objetivo

Implementar una Red Generativa Adversaria (GAN) utilizando TensorFlow/Keras para comprender el funcionamiento del generador y discriminador en la creación de imágenes sintéticas.

## Dataset utilizado

Fashion MNIST.

## Arquitectura implementada

- Generador basado en capas Dense y Conv2DTranspose.
- Discriminador basado en capas convolucionales Conv2D.

## Evidencia principal

El modelo logra generar imágenes sintéticas similares a prendas de vestir mediante entrenamiento adversarial entre el generador y el discriminador.

## Tecnologías utilizadas

- Python
- TensorFlow/Keras
- NumPy
- Matplotlib

## Cómo ejecutar

1. Abrir el notebook en Google Colab.
2. Ejecutar todas las celdas en orden.
3. Esperar el entrenamiento y visualizar imágenes generadas.

# Semana 14 – Fine-Tuning de Stable Diffusion

## Objetivo

Implementar un proceso básico de Fine-Tuning utilizando Stable Diffusion y la librería Diffusers en Google Colab para comprender la adaptación de modelos generativos preentrenados.

## Tecnologías utilizadas

- Python
- TensorFlow
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion
- Google Colab

## Evidencia principal

Se generaron imágenes antes y después del Fine-Tuning para analizar visualmente el impacto del ajuste del modelo utilizando un dataset personalizado.

## Resultados

El modelo mostró capacidad de adaptación a nuevas características visuales, evidenciando el funcionamiento del Fine-Tuning en modelos generativos.

## Cómo ejecutar

1. Abrir el notebook en Google Colab.
2. Instalar dependencias automáticamente.
3. Subir dataset personalizado.
4. Ejecutar todas las celdas en orden.
5. Visualizar imágenes generadas y comparación final.
